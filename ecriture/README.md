# Écriture — d'une fiche épisode au scénario, puis au plan de production

Générique : vaut pour toute série. Ce qui est propre à une série (structure, dispositif, cast, registres) est dans sa bible, par exemple `iletaitunefois/serie/BIBLE-Les-Decouvreurs.md`.

```
ecriture/
  METHODE-ecriture.md     hiérarchie des sources, calibrage, contraintes de fabrication dès l'écriture,
                          format du scénario, vérifications par script, plan de production en six sections
  PROMPT-MAITRE.md        le prompt qui enchaîne les deux étapes (scénario, puis plan de production)
  novelcrafter/           importer un épisode dans Novelcrafter : mode d'emploi et les deux scripts
                          (manuscrit technique généré depuis le scénario, vérification de la prose)
```

L'ordre : fiche épisode + bible de la série + fiche personnages → **scénario** (tableau de plans à huit colonnes, zone verrouillée) → **plan de production** (diagnostic, formules de style, roster avec planches de continuité, tableau révisé, prompts de la première séquence, alertes) → `atelier/GUIDE-preparation-episode.md` avant la première image.
